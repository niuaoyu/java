## 3. 当前问题

解决方法：错误思想，代码不是手停口停，代码是少数边际成本为零，但产物可以被反复调用，一个工具能卖给1w人，之所以觉得手停口停，是只见过打工形式，没见过可以做产品，工具，一次开发可以持续收费，也可以做内容（教代码），建立粉丝和信任，也可以用代码做投资。当下问题不是离开代码，而是什么时候把代码从打工形式转变成另外三种形式（工具，课程，研究），这个转换核心是当下最看不上的东西，如何把代码练到能靠他赚钱？之所以抵触代码，本质是对打工抵触，不是对代码抵触，把打工跟代码分开，并且认为打磨这个技能是未来切换形式的必要条件，练他就不是妥协，是备料

### 谎言1："我要做有复利的事"

**真相**：所有复利都建立在短期反馈上。

* 读书有复利？前提是**你能把书里的东西用出来**。你能吗？
* 健身有复利？前提是**你的身材让你更自信**。你更自信了吗？
* 认知有复利？前提是**你能用认知赚到钱**。你赚到了吗？

**没有短期反馈的"复利"，只是逃避的借口。**

真正的复利是：

* 打一次比赛 → 拿一次奖 → 赚一次钱 → **知道自己能赚钱** → 自信增加 → 下次更敢尝试
* 做一个项目 → 有人用 → 拿到反馈 → **知道自己能做出有用的东西** → 技能增加 → 下次做得更好

你现在的"复利"是：读书 → 买课程 → 听力 → **什么都没发生** → 继续读书 → 继续买课程 → 继续听力

**这不叫复利，这叫原地转圈。**


### 谎言2："我不想跟别人一样"

**真相**：你不是不想跟别人一样，你是害怕跟别人比。

看这段：看到他们在那算获奖证书算分，我一点没有，有点难受

你难受什么？难受的是**你没有，而他们有**。

如果你真的"不在意"，你根本不会难受。

**你在意，但你假装不在意，因为假装不在意比承认自己不如别人更容易。**


"为什么不敢竞争？"，**因为你把自尊压在了"潜力"上，而不是"成就"上。**，你的自信来源：❌ 不是"我做成过什么"，✅ 而是"我有潜力做成什么"，所以你害怕竞争，因为竞争会暴露：**你的潜力可能没你想的那么大。** **解药**：把自尊建立在"我尝试过"上，而不是"我成功过"上。


"为什么懒得算综测？"，**因为你潜意识里知道：算了也不高，算了就得承认"我确实不如别人"，不算，你还能保留"我只是懒得算"的幻觉**，解药：算一次，看到真实分数，接受它，然后想办法提高。

"为什么觉得别人面目可憎？"，**因为他们做了你不敢做的事（去争、去卷），而且成功了，这让你的"不屑"显得像是"不敢"**  你对富哥舒服，是因为他不跟你竞争，他的存在不威胁你的自尊。**解药**：停止把别人的成功当成对你的否定。他们拿奖，不代表你没价值。

"想当然，不遵循规则"，**因为你的认知都是"看来的"，不是"做出来的"**，看书 ≠ 理解世界、买课程 ≠ 掌握技能、听别人讲 ≠ 自己经历。**真正的认知来自：做一件事 → 失败 → 复盘 → 再做 → 成功。** 你跳过了前面所有步骤,直接想要"成功"。


现在的状态，不是"慢半拍"，而是**根本没上场**。别人在场上打球，有人投进、有人投丢、有人被盖帽、有人拿MVP。你在场边：做俯卧撑、练运球、看比赛录像、买篮球课程。然后你问："为什么我总觉得慢半拍？"，**因为你他妈压根没上场。**
