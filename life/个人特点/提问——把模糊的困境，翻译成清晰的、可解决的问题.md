把模糊的困境，翻译成清晰的、可解决的问题，需要收集什么信息，才能知道问题究竟在哪里？

一套自我追问的模式
```
到底发生了什么？只描述可观察事实，不急着评价。
什么地方让我不满意？
我希望它变成什么样？
为什么我希望这样？背后真正目的是什么？
现状与目标具体相差什么？
把整个过程按步骤展开，第一次出现问题在哪里？
我认为原因是什么？这是事实、推测，还是情绪判断？
为了验证原因，我需要知道什么？
我已经尝试过什么？实际结果分别是什么？
从这些失败中可以排除什么？
有哪些现实条件不能改变？
如果目前只能解决一个子问题，解决哪个最有价值？
我需要的是知识、诊断、方案、决策、反馈，还是执行监督？
最后，把它压缩成一句可以回答的问题。
```

对一个混乱的人其实是不知道怎么梳理的，只会说一些情绪或者感受，需要改骨架

情境 → 目标 → 现状 → 差距 → 诊断 → 尝试 → 约束 → 问题
【情境】事情发生在什么具体场景？有哪些与决策有关的背景？
【目标】我到底希望发生什么？做到什么程度算解决？
【现状/差距】现在实际是什么样？与目标差在哪里？
【卡点/诊断】整个过程中，具体在哪一步失败？我认为可能是什么原因？哪些只是猜测？
【尝试】我已经试过什么？具体怎么做的？发生了什么？这说明什么？
【边界】哪些东西暂时不能改变？我有多少时间、金钱、资源以及风险承受能力？
最后才是：【问题】基于以上信息，我现在最希望解决的一个具体问题是什么？注意最后三个字：“一个问题”。很多困境之所以越想越乱，是因为实际上里面塞了七八个问题。




核心逻辑只有一句话：“现在是什么样 → 我希望是什么样 → 中间差在哪里 → 为什么有这个差距 → 我究竟需要解决哪一个差距。”

困难不等于问题，学习效率低是困境而不是问题，要进一步问什么叫效率低？

目标不是说想变好，想学英语，想提高效率，这只是方向，目标只需要回答一个问题，**“什么结果出现以后，我会认为这个问题暂时解决了？”**，英语变好的目标是6个月后能不靠字幕看懂YouTube这叫目标，因为这有一个非常具体非常直观的判断，到底达没达到目标。目标也不一定有数字，但必须有完成的标准

卡点要回答的是，“从A走到B的时候，具体在哪一步停住了？”，单单说不会编程不够，要回答的是我现在会什么——A初始点？我想要实现什么目标——b目标点？在走的过程当中遇到什么问题？这个问题就是卡点，如果卡点说不上来，就说事实，在做什么事情的时候做不下去。

边界的本质是说，去掉那些看着有用但对我当下没有意义的方法，因为要考虑时间，金钱，资源，不可改变的条件，想学英语每天三小时一定可以，但是上班哪有那么多时间？

**好问题 = 背景 + 目标 + 卡点 + 边界 + 补充。** 提问前先自问：**我在做什么？我想要什么？我卡在哪？我试过什么？我有什么限制？** 把这五个问题写下来，你的问题就已经解决了一半。因为**理清问题的过程，本身就是解决问题的一部分。**

```
【背景】身份/阶段(6月6级) +现在的问题+证据（阅读正确率50%。每篇12分钟）。我在做什么？目前处于什么阶段？
【目标】期限(三个月)+成功证据(拿到金融开发offer)。我想要达到什么结果？怎么算成功？最晚什么时候？最小可接受结果是什么？（越具体越好）
【卡点】写差距，不写情绪，什么情况下做了什么结果是什么？每次面对要梳理论文的目标时刻，总会觉得问题太大而不愿动手，结果是一直拖延
【边界】有多少（时间、预算、资源、底线），每天十小时，没有钱，无限ai，必须四个月内拿到实习
【补充】我试过什么？排除什么？测猜的原因是？

在【背景】下，我想在【期限】达到【目标】。目前卡在【卡点】，试过【尝试】但【结果】。我能投入【资源】，不能牺牲【限制】。我猜【假设】，已排除【排除项】。请帮我【具体请求】。
```

好问题的标准不是字多，而是：
- **具体**：有时间、场景、人物、频率、程度、证据。
- **可验证**：怎么算解决？用什么指标判断？
- **可行动**：别人能据此给建议、做选择、设计下一步。
- **单一**：一次只问一个核心问题，不混五个问题。


常见错误：
1. 没提供背景信息，不够具体，太模糊，上来就问，泛泛问得不到自己想要的东西
2. 把责任甩锅给别人，没有摸清楚自己到底要的是什么？自己到底核心目的是什么都没说清楚，


原则
1. 具体详细：背景+目标+卡点（问题所在）+边界（预算，时间）**这些怎么说的具体？**
2. 如何定义清楚一个问题？如何提出一个好的问题？如何提出我当前的问题是什么？需要提供什么样的背景信息？
3. 如何理清自己的学习方法，既能，时间安排，具体情境如何想，做过那些尝试？能知道自己解决问题的一个模式？




框架
1. 四个框架：背景+目标+卡点（问题所在）+边界（预算，时间），好问题不是码字，而是过一遍这四个问题




不同人群
1. 向ai问，要提供详细的背景信息
2. 向领导专家问，背景可以弱化（他们更专业），直接说卡点
3. 自我提问，要定义清楚目标是什么，想不出办法更多的是没想清楚要去哪，目标是什么，那自然边界和卡点都不知道
