## 飓风游戏（Hurricane Game）面试抱佛脚指南

因为这个岗位是 2026 年 7 月刚发布的，又是你熟悉且学过 Unity 的领域，请在投递前花 **1 个小时**突击这两个游戏测试必问问题：

1. **“如果一个玩家反馈：我的背包里少了一个道具，你怎么查？”**
    
    - _满分回答（利用你的 SQL 优势）_：
        
        1. 首先记录玩家的 UID、道具减少的精确时间。
            
        2. 去游戏后台**用 SQL 查询**该玩家在该时间段的`道具变更日志表（Log Table）`，看是否有扣除记录（是误操作卖出了、还是进副本消耗了）。
            
        3. 如果日志显示异常扣除（没有任何关联事件），我会去 **Unity** 看看背包系统的扣除逻辑代码，或者本地复现这个网络丢包/连点情况，看是否存在前端频繁点击触发了两次扣减 API 的 Bug。
            
2. **“怎么测试游戏里的一把新武器/一个新英雄？”**
    
    - _背诵框架_：我会从四个维度去测：
        
        - **功能测试**：它的攻击力、技能释放、冷却时间（CD）是否跟策划文档一致？
            
        - **表现测试**：它的 Unity 特效、音效、动作动画是否有穿模、穿音或者掉帧？
            
        - **边界/极端测试**：在极限攻速下连续释放、或者在断网重连、极限低血量时使用，是否会触发 Bug？
            
        - **兼容性测试**：在不同的手机/设备上，这个武器的 UI 渲染是否正常？
