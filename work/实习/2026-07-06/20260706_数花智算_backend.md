面试前如何“务实地”应对 Agent 提问？
既然简历往 Agent 靠了，面试官一定会问你对大模型和 Agent 的看法。因为你投的是实习生，记住这个务实、不吹大的话术框架：

面试官：“你简历里写了解大模型和 Agent，你对它的理解是什么？”

务实回答：

“我认为现在的 LLM 虽然‘能查数、能聊天’，但直接给企业用会遇到两个大问题，这也是我特别认同贵公司产品聚焦‘第一公里和最后一公里’的原因。
第一公里是输入：大模型再聪明，如果灌进去的数据口径不一致、有缺失值，它就会胡说八道（幻觉）。所以必须用 SQL 和 Pandas 把数据洗干净、建立标准化映射。
最后一公里是输出：用户要的不是一堆冷冰冰的代码或者一句话，而是需要大模型自动把分析结论，变成可配置的、格式规范的经营简报或风险预警。
虽然我目前没有从头微调过千亿级大模型，但我精通 Python/SQL，自学过金融知识，我相信我能干好这些大模型落地时最需要的‘数据脏活累活’。”

面试官：“简历里写了 Prompt（提示词），你平时怎么用？”

务实回答：

“我日常会深度使用 Claude 和 Gemini 辅助开发。我发现写好 Prompt 的核心在于结构化（如使用 Role-Task-Context-Constraint 框架）以及提供 Few-Shot（少样本提示）。在金融场景下，如果直接让大模型写分析报告，它可能语气很不专业。我会通过 Prompt 塞给它一个标准的专家思维链（CoT），限制它的输出格式，并给它 2 个标准的金融简报作为模板，这样它生成的报告就能真正落地到业务日常动作中。”
