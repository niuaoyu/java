
run terminal 总是找不到

在项目根目录创建 `.env` 文件（推荐）

在 `/home/nay/final/rag/` 下创建 `.env` 文件：

```bash
# .env
PYTHONPATH=/home/nay/final/rag
```

然后在 `.vscode/settings.json` 里配置：
```json
{
    "python.envFile": "${workspaceFolder}/.env",
    "python.terminal.activateEnvironment": true
}
```
这样每次 VS Code 启动新终端时，会自动读取 `.env` 并注入 `PYTHONPATH`

这样直接run  terminal就可以了
