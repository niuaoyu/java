
debug始终问自己：现在在哪？为什么到这？现在手里是什么数据？从上一个断点到这发生什么变化？下一个断点去哪？

“黄色高亮/当前行”通常表示：这一行是“**接下来准备执行**的代码”，不是“已经执行完的代码”。

1. continue继续(F5)：一个断点一个断点的读，不关心中间，**不停**，一直运行到下一个断点（异常或程序结束）
2. step over单步跳过(F10)：逐行执行，如果当前行是函数，不进入函数
3. step into (F11)：执行某行时，如果遇到函数就**进去**函数内部，逐行调试（==这意思是，如果逐行执行，没遇到函数也就是跟step over效果一样？==）
4. step out (shift f12)：已经在某个函数内部，不想看函数剩余部分，直接把当前内容执行完，想直接回到调用处





Step Over (F10) 是什么？= 执行当前这一行，如果这行有函数调用，也不进入函数内部，直接把整个函数执行完，然后停在下一行。

一句话：
- F11 = 进去看
- F10 = 跨过去
- F5 = 直接跑
```python
def add(a, b):
    result = a + b      # 第2行
    return result       # 第3行

def main():
    x = 10              # 第6行
    y = 20              # 第7行
    z = add(x, y)       # 第8行  ← 断点停这里
    print(z)            # 第9行

main()
```

假设断点停在**第8行** `z = add(x, y)`：

按 F11 (Step Into)，会**进入** `add` 函数内部：
- 停在第2行 `result = a + b`
- 再停在第3行 `return result`
- 然后回到第9行
👉 你能看到 `add` 里面怎么算的。

按 F10 (Step Over)，**不进** `add`，直接把 `add(x, y)` 执行完：
- 直接跳到第9行 `print(z)`
- `z` 已经等于 30 了
👉 你只关心结果，不关心 `add` 内部细节。

按 F5 (Continue)，如果第9行之后没有断点，程序**直接跑完退出**，你啥也看不到。


## 什么时候用 F10？

当你**确定某个函数没问题**，不想浪费时间进去逐行看，就用 F10 跨过去。

比如你调用的是 `print()`、`len()`、`math.sqrt()` 这种标准库函数，进去也没意义，直接 F10 跳过。

## 记忆口诀

- **F11 进去**（Into = 进入）
- **F10 跨过**（Over = 跨过）
- **F5 放行**（Continue = 继续跑）
