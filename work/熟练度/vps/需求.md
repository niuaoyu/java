
把VPS 需求重新梳理成一份“购买标准”。

要的不是 RDP、不是 LXC 玩具机，也不是独立服务器。真正需要的是

```text
一台便宜、稳定、、非大陆/港澳地区的 Linux VPS / Cloud Instance
有 root 权限的 Ubuntu VPS，
主要用来访问国外网络，给自己和实验室十几个人轻量使用
备用跑API relay、Hermes、自动化脚本
```
预算：月付9 美元以内。年付600 CNY 以内，越便宜越好

主要用途是：主要作为实验室十几个人轻量共用代理节点，多余性能做API 中转与统一分发、自动化脚本、Hermes / Agent、Cloudflare 部署

希望：不要随时跑路、最好是大厂或有一定声誉的商家、可以长期用，优先考虑Leaseweb、Hetzner、OVHcloud、Netcup、HostHatch、RackNerd 促销机作为备选。不考虑无名小商家、只收加密货币的商家、不退款、不保证可用的 LXC 小鸡、共享 RDP

地区要求：不要中国大陆、香港、澳门。可以接受新加坡、日本、韩国、澳大利亚、欧洲、美国、加拿大。兼顾备用代理 / 实验室访问体验，新加坡 > 日本 > 澳大利亚 > 美国西海岸 > 欧洲/加拿大

IP个数：十几个人用，最好ip多个，没有也没关系有办法免费扩ip
流量需求：600GB/月，主力用途，流量不能太少、单 IP 共享会有风控风险、被封后所有人受影响
带宽需求：最低要求100 Mbps，如果多人一起用1Gbps 或更高更好
不需要独立服务器，不是在本机跑大模型，也不需要大量存储、不需要 GPU、不需要超强 CPU、需要足够内存和稳定 Linux 环境
