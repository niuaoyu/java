# 操作
**ls 列出⽬录内容** 
ls ：列出当前⽬录下的⽂件和⼦⽬录。
ls -l ：以列表形式显示详细信息，包括⽂件权限、所有者、⼤⼩和最后修改⽇期。
ls -a ：显示所有⽂件，包括隐藏⽂件（以.开头的⽂件）。
ls -lh ：以易读的格式显示⽂件⼤⼩（例如，⽤ K、M、B 表示）。

**mkdir 创建新⽬录** 
mkdir directory ：创建⼀个新⽬录。
mkdir -p directory/subdirectory ：创建⼀个新⽬录和⼦⽬录。

**rm 删除⽂件或⽬录** 
rm file ：删除⽂件。
rm -r directory ：删除⽬录及其所有内容。
rm -f file ：强制删除⽂件，不提示。
rm -rf directory ：强制删除⽬录及其所有内容，不提示。

**cp 复制⽂件或⽬录** 
cp source target ：复制⽂件。
cp -r source target ：递归复制⽬录极其内容。

**cat 查看⽂件内容** 
cat file ：显示⽂件内容。
cat file1 file2 ：连接多个⽂件并显示内容。
cat > file ：创建⼀个新⽂件并输⼊内容，按 **Ctrl + D** 保存退出。
cat >> file ：追加内容到⽂件末尾。
cat file1 file2 > file3 ：合并 file1 和 file2 的内容，并将合并后的内容存储到 file3 中。

**echo 输出⽂本** 
echo "Hello, World!" ：输出⽂本。
echo "Hello, World!" > file ：将输出重定向到⽂件。
echo "Hello, World!" >> file ：将输出追加到⽂件末尾。
echo -e "Hello\nWorld" ：⽀持转义字符。
echo -n "Hello, World!" ：不换⾏输出。
echo $? ：显示上⼀个命令的退出状态。
echo $SHELL ：显示当前 shell 的类型。

**head 和 tail 查看⽂件头和尾** 
head file ：显示⽂件的前 10 ⾏。
head -n 20 file ：显示⽂件的前 20 ⾏。
tail file ：显示⽂件的最后 10 ⾏。
tail -n 20 file ：显示⽂件的最后 20 ⾏。

**vim 编辑⽂件** 
vim file ：编辑⽂件。
i ：切换到插⼊模式。
Esc ：退出插⼊模式。
:w ：保存⽂件。
:q ：退出⽂件。
:wq ：保存并退出⽂件。
:q! ：强制退出⽂件。

**chmod 修改⽂件权限**
![[1780383814183_d.png]]
Linux 中的权限可以应⽤于三种类别的⽤户：1.⽂件所有者（**u** user）,2.与⽂件所有者同组的⽤户（g group）,3.其他⽤户（o others）

1.符号模式：读（r）、写（w）、执⾏（x）、所有（a）
1. chmod u+w file ：给⽂件所有者添加写权限。 
2. chmod g-r file ：移除组⽤户的读权限。 
3. chmod o+x file ：给其他⽤户添加执⾏权限。 
4. chmod u=rwx,g=rx,o=r file ：设置⽂件所有者具有读写执⾏权限，组⽤户具有读执⾏权限，其他⽤户具有读 权限。

2.数字模式：使⽤三位⼋进制数来表示权限，每位数字代表不同的⽤户类别（所有者、组、其他⽤户），数字是其各⾃权限值的总和：读（r）= 4、写（w）= 2、执⾏（x）= 1
权限模式可以是从 0（⽆权限）到 7（读写执⾏权限）的任何值。
1. chmod 755 file：使得⽂件所有者有读写执⾏（7）权限，组⽤户和其他⽤户有读和执⾏（5）权限。
2. chmod 644 file：使得⽂件所有者有读写（6）权限，⽽组⽤户和其他⽤户只有读（4）权限。

**zip压缩文件**
最常⽤的包括：gzip、tar 、和zip
1. gzip
	1. gzip filename ：将⽂件压缩成.gz 格式。原⽂件会被压缩后的⽂件替换。
	2. gzip -k filename ：压缩⽂件但保留原⽂件。
	3. gzip -d filename.gz ：解压.gz 格式的⽂件。
2. tar：将多个⽂件和⽬录打包成⼀个⽂件（通常为.tar ⽂件）的⼯具，它可以与gzip 结合使⽤来进⾏压缩。
	1. 打包并压缩，tar -czvf archive_name.tar.gz directory_or_file ：创建⼀个 gzip 压缩的 tar 包。
	   ![[1780385226136_d.png]]
	2. 解压， tar -xzf archive_name.tar.gz ：解压⼀个 gzip 压缩的 tar 包。
3. zip：
	1. 压缩⽂件或⽬录，zip -r archive_name.zip directory_or_file ：压缩⽂件或⽬录到.zip 格式。**是把directory_or_file文件或者目录，压缩为archive_name.zip这个东西**
	2. 解压，unzip archive_name.zip ：解压.zip 格式的⽂件。

**tree 显示⽬录结构** 
tree ：以树形结构显示⽬录。
tree -L 2 ：只显示两层⽬录。
tree -d ：只显示⽬录。
tree -a ：显示所有⽂件和⽬录。
tree -h ：以易读的格式显示⽂件⼤⼩
