### 看代码的“前后左右”

| 操作          | 快捷键 (Win/Linux) | 快捷键 (Mac)          | 用途                                                |
| ----------- | --------------- | ------------------ | ------------------------------------------------- |
| **跳转到定义**   | `F12`           | `F12`              | 跳到函数/类的定义处。**读代码最核心的操作**。                         |
| **跳转到引用**   | `Shift + F12`   | `Shift + F12`      | 查看**“谁调用了这个函数”**。你想知道 `build_registry` 被谁用了，就用这个。 |
| **返回上一位置**  | `Alt + ←`       | `Ctrl + -`         | **神键！** 看完定义后按它，直接跳回你刚才读代码的地方。                    |
| **前进到下一位置** | `Alt + →`       | `Ctrl + Shift + -` | 与上面相反，用于“反悔”后退操作。                                 |


### 全局搜索——用关键词“大海捞针”

当你只知道一个函数名、类名或变量名（比如你之前问的 `attempt.completed`），但不知道它在哪时：

| 操作 | 快捷键 (Win/Linux) | 快捷键 (Mac) | 用途 |
| :--- | :--- | :--- | :--- |
| **全局搜索** | `Ctrl + Shift + F` | `Cmd + Shift + F` | 在**整个项目**里搜索文本（支持正则）。看到 `emit` 或 `publish` 就是发射点。 |
| **搜索符号 (Symbol)** | `Ctrl + T` | `Cmd + T` | 输入 `#attempt` 或 `@execute`，直接搜索所有**类名、函数名**，跳过注释和字符串。 |
| **文件内搜索** | `Ctrl + F` | `Cmd + F` | 只在当前打开的文件里搜索。 |

> **心法**：找“发射点”用全局搜索（搜事件名），找“函数定义”用符号搜索（`Ctrl+T`）。

| 操作 | 快捷键 (Win/Linux) | 快捷键 (Mac) | 用途 |
| :--- | :--- | :--- | :--- |
| **快速打开文件** | `Ctrl + P` | `Cmd + P` | 输入文件名（比如 `session_service.py`），回车打开。**不用去点鼠标找文件树**。 |
| **打开/关闭侧边栏** | `Ctrl + B` | `Cmd + B` | 快速隐藏文件目录树，让编辑区更大，专心读代码。 |
| **在侧边栏中定位** | - | - | 在编辑器里右键点击文件标签 → **在侧边栏中显示 (Reveal in Explorer)**。 |

### 🔬 第四步：看结构——“鸟瞰”当前文件

当你打开一个几百行的文件（比如 `agent_loop.py`），想快速了解它里面有哪些函数、类，而不是从头滚动到尾：

| 操作 | 快捷键 (Win/Linux) | 快捷键 (Mac) | 用途 |
| :--- | :--- | :--- | :--- |
| **打开大纲** | `Ctrl + Shift + O` | `Cmd + Shift + O` | 在文件顶部弹出一个下拉框，列出该文件所有的**函数、类、变量**。输入 `@` 可快速筛选。 |
| **折叠代码块** | `Ctrl + Shift + [` / `]` | `Cmd + Option + [` / `]` | 把大段函数折叠起来，只留函数名，像看目录一样扫读。 |

### 🧠 第五步：进阶心法——用“业务关键词”而非“代码变量”去搜索

这是从“新手”到“老手”的重要区别。**不要只搜代码里的变量名，要搜业务概念。**

| 搜什么 | 怎么搜 | 为什么有效 |
| :--- | :--- | :--- |
| **业务术语** | 直接搜中文或英文业务词 | 比如你想找“回测逻辑”，不必搜 `def run_backtest`，直接搜 `"backtest"` 或 `"回测"`，因为开发者在写日志或注释时一定会提到这个词。 |
| **错误信息** | 搜 `"timeout"` 或 `"failed to connect"` | 比搜 `Exception` 更精确，直接定位到报错逻辑的位置。 |
| **API 路由** | 搜 `"/sessions"` 或 `"@app.post"` | 快速找到**对外暴露的接口**（Controller 层），从入口往下读，比从深层的工具类往上找要容易理解。 |

---

### 📝 总结：读一个复杂项目的“三步连招”

1. **定位入口**：先搜 `@app.post` 或 `/sessions` 或 `main` 函数，找到请求的**入口文件**。
2. **画流程图**：用 `F12` 跟进去，一个函数一个函数地跳，看到 `Registry`、`Service` 这种大面积调用的，用 `Shift + F12` 看引用。用纸笔或脑图记录调用顺序。
3. **断点调试**：在关键行（比如 `attempt.created` 的 `emit` 处）按 `F9` 打红点，启动调试（`F5`），**跑一遍业务流**。观察变量变化，比纯静态看代码效率高 10 倍。

快速定位当前 Python 文件的内容，**关键不在于“滑”，而在于“跳”**。鼠标滚轮滚动太慢，下面这几种方法可以让你在几百行的文件里瞬间到达想去的位置：

## 方法一：打开文件大纲（最推荐，一眼看全貌）

**快捷键**：`Ctrl + Shift + O`（Mac：`Cmd + Shift + O`）

- 会弹出一个**当前文件所有函数、类、变量的列表**。
- 输入关键词（比如 `build`）可以实时筛选。
- 点击列表项，直接跳转到对应位置。

> **这是读陌生代码时最常用的操作**，比滚动快 10 倍。

## 方法二：利用“缩略图”滚动（可视化定位）

在编辑器右侧有一块**垂直的缩略图**（代码迷你地图）：
- 鼠标在缩略图上**上下拖动**，可以快速滚动到文件的任意位置。
- 缩略图里浅色/深色块代表代码密度，你可以根据“哪一段颜色比较密集”判断函数聚集区。

**如何开启/关闭缩略图**：
- 菜单栏 → **查看 → 显示缩略图**（或 `Ctrl + Shift + P` → 输入 `Minimap Toggle`）

## 方法三：用“面包屑”导航（查看当前位置层级）

在编辑器**顶部**有一行“面包屑”（Breadcrumbs），显示当前光标在哪个类、哪个函数里：
- 点击面包屑上的**函数名**，会下拉列出该文件里所有同级的函数/类，直接点击跳转。
- 如果没看到面包屑，用 `Ctrl + Shift + P` → 输入 `View: Toggle Breadcrumbs` 开启。

## 方法四：搜索当前文件内的关键词

- **快捷键**：`Ctrl + F`（Mac：`Cmd + F`）
- 输入你想找的**函数名**、**变量名**或**注释关键词**。
- 按 `Enter` / `Shift + Enter` 跳转到上/下一个匹配项。
- 配合搜索框右边的 **“...”（筛选按钮）**，可以选择“区分大小写”或“正则匹配”。

## 方法五：直接用“跳转到行”快速定位

如果你已经知道目标行号（比如从报错信息或 `grep` 输出中看到 `:42`）：
- 快捷键：`Ctrl + G`（Mac：`Cmd + G`）
- 输入行号（比如 `42`），回车直达。

## 方法六：折叠代码块（把长文件变短）

- `Ctrl + Shift + [`：折叠当前光标所在的代码块（函数/类/循环）
- `Ctrl + Shift + ]`：展开
- `Ctrl + K` + `Ctrl + 0`：折叠**所有**顶级代码块（只看函数名和类名，不看内部）
- `Ctrl + K` + `Ctrl + J`：展开所有

折叠后，几百行的文件可能只显示十几行“标题”，这时候滚动找目标就非常快。

## 最佳实践（组合拳）

当你进入一个不熟悉的 Python 文件时，按这个顺序操作：

1. `Ctrl + Shift + O`：扫一眼大纲，看有哪些函数/类
2. 点击最像“入口”的那个函数（比如 `main` 或 `execute`），跳过去
3. 滚动时结合**缩略图**或**面包屑**看上下文
4. 如果遇到陌生的子函数调用，按 `F12` 跳转到定义看，看完按 `Alt + ←` 回来
5. 需要全局搜关键词时用 `Ctrl + Shift + F`（而不是在当前文件里滚）

## 快捷键速查表（只记最核心的）

| 操作 | Win/Linux | Mac |
|------|-----------|-----|
| 当前文件大纲 | `Ctrl + Shift + O` | `Cmd + Shift + O` |
| 当前文件搜索 | `Ctrl + F` | `Cmd + F` |
| 跳转到行号 | `Ctrl + G` | `Cmd + G` |
| 跳转定义 | `F12` | `F12` |
| 返回上一位置 | `Alt + ←` | `Ctrl + -` |
| 折叠当前块 | `Ctrl + Shift + [` | `Cmd + Option + [` |
| 展开所有 | `Ctrl + K` + `Ctrl + J` | `Cmd + K` + `Cmd + J` |

---

**一句话总结**：想找当前文件里的内容，最快是 **`Ctrl + Shift + O`（大纲）** + **`Ctrl + F`（搜索）**，配合 **`Alt + ←` 返回**，基本不用鼠标滚轮。

如果你习惯用鼠标，那就在右侧**点击滚动条上的彩色标记**，那是另一种快速跳转方式。😊


#### 删除/关闭文件

|操作|快捷键 (Win/Linux)|快捷键 (Mac)|说明|
|---|---|---|---|
|**关闭当前文件**|`Ctrl + W`|`Cmd + W`|关闭当前编辑的标签页|
|**关闭所有文件**|`Ctrl + K` + `Ctrl + W`|`Cmd + K` + `Cmd + W`|一次关闭所有打开的标签页|
|**关闭其他文件**|`Ctrl + K` + `Ctrl + Shift + W`|`Cmd + K` + `Cmd + Shift + W`|保留当前，关闭其他所有标签页|
