

### 看代码的“前后左右”

| 操作              | 快捷键 (Win/Linux) | 快捷键 (Mac)          | 用途                                                |
| --------------- | --------------- | ------------------ | ------------------------------------------------- |
| **跳转到定义**       | `F12`           | `F12`              | 跳到函数/类的定义处。**读代码最核心的操作**。                         |
| **跳转到引用**       | `Shift + F12`   | `Shift + F12`      | 查看**“谁调用了这个函数”**。你想知道 `build_registry` 被谁用了，就用这个。 |
| **返回上一位置**      | `Alt + ←`       | `Ctrl + -`         | **神键！** 看完定义后按它，直接跳回你刚才读代码的地方。                    |
| **前进到下一位置**     | `Alt + →`       | `Ctrl + Shift + -` | 与上面相反，用于“反悔”后退操作。                                 |
