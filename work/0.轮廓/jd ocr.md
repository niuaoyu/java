筛选逻辑**必须同时满足的条件：

3. 先对链接的**可见文本**（公众号标题、摘要）做关键词过滤，剔除明显不相关的（比如“机械”“射频”“FPGA”等）。

公告级切分（修复粒度问题），一篇公告里 `现场工程师 / 远程作业工程师 / 维修工程师 / 软件工程师 / 机械工程师` 被拼成一个"职位"字段。你需要的不是"这条公告是不是开发岗"，而是"**这篇公告里有哪些岗位是 Agent/AI 应用开发岗**"。切分方法：**在 LLM 结构化解析这一步，改变 prompt 的输出结构。** 不要让 LLM 输出"一篇公告的结构化结果"，而要它输出"**这篇公告里所有岗位的列表，每个岗位独立结构化**"。
