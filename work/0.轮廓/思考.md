# 学习的方法
1. 如何学项目？不要担心，所有的后端或者程序都有一个模板，各种层，不需要担心，熟练就行。
	1. 刚看视频操作的时候，看完一个，先别开始下一个，把流程图对着脑子画下来，这就是自己的收获，一点点做。
	2. 等到所有的模块都这样做完后，代码也跑通了，事实上每一个模块都知道数据是怎么跑的，包括如何配置
	3. 开始对某个部分（常见的功能）进行复制，比如，新加一个属性或者表，从头到尾改一遍数据，算第一次微调项目
	4. 接着让ai使劲拷打自己更改的这个部分，问出各种面试题以及答案。
2. 如何记笔记？只记三点，第一是框架图（需要做完项目后理解透，自己画一个），第二是每个模块，每个步骤只记“为什么？”，为什么用这个不用别的？这个要多问ai，最后是只记环境搭建或者其他的bug问题。


# 语言的选择
1. AI Agent开发 VS Ai Agent应用 VS LLM
	1. rag, Agent架构熟悉这2个东西的前提下，找个开源的ai客服系统，试着跑起来，然后套招聘网站哪些要求去理解看看？
	2. 先看 Agent 设计书籍，然后拿一个小的，比如 pi-mono 的源码，利用 AI 分析一下。不懂的可以问AI。两天就差不多会了
2. golang并不小众，只是很多人还坚持着java不往前走而已。但现实是，更多的公司在往新语言走，比如golang，rust之类的（rust学习门槛高，golang会更合适）而且golang光k8s生态，就一大堆项目了.再者，ai时代，其实，用什么语言，更多的是看这个语言实际有什么优势。
	1. 我们部门主要搞云原生之类的，我现在也是go的大力崇拜者
	2. 我用的开源项目都是golang的，rust确实门槛太高了，像minio，gitea，caddy这些很出名的工具都是golang写的。其他门道的，像sing-box，这要真用java写，怕是要废老鼻子劲了，也不好用 ，但是现在来看，AI写rust问题不是很大，我现在在flutter里嵌入到的rust代理模块，用AI写的就很好用。
	3. 不是不往前走，不都是岗位所迫嘛，主要是Java岗位多，然后学点别的用不上的情况下很快就会遗忘
	4. 2013 年 Docker 发布，2014 年 K8S 发布，然后 Go 就一路狂飙，差不多相同时期，七牛开始疯狂布道 Go，2015 年 Ethereum 上线，链圈及其关联的大量项目都是采用 Go 的
	5. rust还是适合更底层的东西，快速迭代的不太适合，太费功夫了。综合性能+迭代速度+易用性+灵活性，还是用golang更适合。
	6. golang感觉还蛮适合ai时代的。ai生成代码是很快，但是生产项目终归得review，ai生成的golang代码相对比较容易读懂 
	7. “不往前走”，主要是旧项目，屎山代码太多。完全重写的话，公司会考虑成本，而且重写产生的bug，有些人会觉得，这是在制造麻烦：“能正常跑的东西，你改他干嘛”所以java的惯性力，会让很多公司还继续使用java，甚至继续招java.但是一些新的公司，或者一些新项目，新的团队，可能就不会继续死磕java。比如字节就是一个非常典型的例子。
3. java可以迅速把一个人的代码能力拉到最高
	1. java其实已经完成了他的使命了.资源占用又大，还搞了一大堆工程化的东西。写项目看起来是方便，但是东西太多，太庞大，太重了。java我用了10来年，后面这8-9年都在用golang，真的是太舒服了，太喜欢golang的简洁哲学.
