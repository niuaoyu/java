
Agent 最关键的不是模型，而是两点：
1. 你给它的规则（项目说明、禁止项、验收标准）
2. 你对改动的审核方式（git diff + 测试）

AGENTS.md / CLAUDE.md / GEMINI.md：这些文件的作用都类似：把“项目怎么跑 + 什么能改/不能改 + 怎么验收”写清楚，让 AI 少犯错。




什么是智能体？——能感知周围环境，并自主做出行动。

只感知，并且行动，可能是遵循既定指令来的，但强就强在这个自主！！！怎么具备自主的能力的？大概率是大模型的突变

发展过程：一开始的条件反射（什么环境—>做出什么反应）的**反射智能体（Simple Reflex Agent）**，但存在模糊的情况，即没有预设的情况，因此引出**基于模型的反射智能体（Model-Based Reflex Agent）**，这种模型有记忆功能，之前反射智能体，只能一个预设前提对应一个结果，如今基于模型的反射智能体，会记忆当前的环境状态，理解当前的环境，对于模糊没有预设的情况会分析。
但这两种都是被动的接受，之后发展出主动想合适的解决办法，**基于目标的智能体（Goal-Based Agent）**，比如GPS，有一个终点目标，主动优化路径，如果目标很多，既要最短也要最省钱也要...这就引出**基于效用的智能体（Utility-Based Agent）**，需要在多个冲突的目标做优化
以上四种都是基于先验知识，也就是监督学习，后俩出现的强化学习，让模型自己学习应该怎么办，这便是**学习型智能体（Learning Agent）** 的核心思想
