# 什么是“Java语句”？

**Java语句** = 一条**可执行的命令**，比如：

| 类型 | 示例 |
|------|------|
| 赋值语句 | `i = 10;` |
| 方法调用 | `System.out.println("hi");` |
| 创建对象 | `new Student();` |
| 控制语句 | `if`、`for`、`while`、`return` |

> 一句话：**能“干活”的代码**，就是语句。

## 二、为什么“类体中方法体外只能定义变量”？

### 类体结构图

```java
class MyClass {
    // ⚠️ 这里：只能定义变量/方法，不能写“执行语句”

    static int i;        // ✅ 变量定义（OK）
    int j;               // ✅ 变量定义（OK）

    // ❌ 下面这行报错！不能直接写语句
    // System.out.println("hello");   // 编译错误

    public void m1() {
        // ✅ 这里可以写语句
        i = 10;              // 赋值语句
        System.out.println(i); // 方法调用
    }

    public void m2() {
        // ✅ 这里也可以访问 i
        i = i + 5;           // 赋值语句
    }
}
```

### 原因（不用背，理解即可）

Java 规定：**类的“骨架”部分只能放成员（变量/方法），不能放动作**。  
动作（语句）必须放在**构造器/方法/代码块**里。

> 类比：盖房子  
> - 类体 = 建筑图纸（画墙、画门）  
> - 语句 = 工人干活的动作（刷漆、拧螺丝）  
> - 图纸上不能写“刷漆”，只能写在施工单（方法）里

## 三、为什么 `static int i;` 可以在不同方法中访问？

```java
class Demo {
    static int i;  // 类变量，属于整个类

    void methodA() {
        i = 10;     // 可以
    }

    void methodB() {
        System.out.println(i);  // 可以，因为 i 还在“类体”这个大家庭里
    }
}
```

**原因**：  
- `i` 定义在**类体中方法外**，属于**成员变量**（又叫字段）  
- 成员变量的作用域 = **整个类体**（所有方法都能看到）  
- 方法的执行顺序不影响访问，因为变量和方法是“平级成员”

> 类比：  
> 一个家庭（类）里有一本家庭相册（`static int i`）  
> 爸爸、妈妈、孩子（不同方法）都可以翻看或往里放照片
## 四、一张图总结

```java
public class Example {
    // ┌─────────────────────────────────────┐
    // │  类体（大括号内）                      │
    // │                                       │
    // │  ✅ 只能放：                           │
    // │  - 变量定义  (int a;)                  │
    // │  - 方法定义  (void m(){...})           │
    // │  - 构造器                               │
    // │  - 静态/实例初始化块                    │
    // │                                       │
    // │  ❌ 不能直接放：                        │
    // │  - a = 10;      (赋值语句)            │
    // │  - System.out... (方法调用语句)        │
    // │  - for/if       (控制语句)             │
    // └─────────────────────────────────────┘

    static int i;      // ✅ 成员变量定义

    void method1() {
        i = 100;       // ✅ 语句：必须在方法内
    }

    void method2() {
        System.out.println(i);  // ✅ 可以访问
    }
}
```
## 五、一句话记忆

> **类体里方法外 = 只能贴“标签”（变量/方法），不能写“动作”（语句）**  
> **`static int i` 是标签，所有方法都能看到它**
