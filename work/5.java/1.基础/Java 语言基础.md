# 什么是“Java语句”？

**Java语句** = 一条**可执行的命令**，比如：

| 类型 | 示例 |
|------|------|
| 赋值语句 | `i = 10;` |
| 方法调用 | `System.out.println("hi");` |
| 创建对象 | `new Student();` |
| 控制语句 | `if`、`for`、`while`、`return` |
注意⚠️
```java
int i = 10;   // 这里的 = 叫“初始化”，不是赋值语句
i = 20;       // 这里的 = 叫“赋值语句”
```
Java规定：
在声明变量时写 = → 叫初始化（属于声明的一部分）
单独写 变量 = 值; → 叫赋值语句（属于执行语句）

## 二、为什么“类体中方法体外只能定义变量”？

### 类体结构图

```java
class MyClass {
    // ⚠️ 这里：只能定义变量/方法，不能写“执行语句”

    static int i;        // ✅ 变量定义（OK）
    int j;               // ✅ 变量定义（OK）

    // ❌ 下面这行报错！不能直接写语句
    // System.out.println("hello");   // 编译错误

    public void m1() {
        // ✅ 这里可以写语句
        i = 10;              // 赋值语句
        System.out.println(i); // 方法调用
    }

    public void m2() {
        // ✅ 这里也可以访问 i
        i = i + 5;           // 赋值语句
    }
}
```

### 原因

Java 规定：**类的“骨架”部分只能放成员（变量/方法），不能放动作**。  
动作（语句）必须放在**构造器/方法/代码块**里。

> 类比：盖房子  
> - 类体 = 建筑图纸（画墙、画门）  
> - 语句 = 工人干活的动作（刷漆、拧螺丝）  
> - 图纸上不能写“刷漆”，只能写在施工单（方法）里

## 三、为什么 `static int i;` 可以在不同方法中访问？

```java
class Demo {
    static int i;  // 类变量，属于整个类

    void methodA() {
        i = 10;     // 可以
    }

    void methodB() {
        System.out.println(i);  // 可以，因为 i 还在“类体”这个大家庭里
    }
}
```

**原因**：  
- `i` 定义在**类体中方法外**，属于**成员变量**（又叫字段）  
- 成员变量的作用域 = **整个类体**（所有方法都能看到）  
- 方法的执行顺序不影响访问，因为变量和方法是“平级成员”
## 四、一张图总结

```java
public class Example {
    // ┌─────────────────────────────────────┐
    // │  类体（大括号内）                      │
    // │                                       │
    // │  ✅ 只能放：                           │
    // │  - 变量定义  (int a;)                  │
    // │  - 方法定义  (void m(){...})           │
    // │  - 构造器                               │
    // │  - 静态/实例初始化块                    │
    // │                                       │
    // │  ❌ 不能直接放：                        │
    // │  - a = 10;      (赋值语句)            │
    // │  - System.out... (方法调用语句)        │
    // │  - for/if       (控制语句)             │
    // └─────────────────────────────────────┘

    static int i;      // ✅ 成员变量定义

    void method1() {
        i = 100;       // ✅ 语句：必须在方法内
    }

    void method2() {
        System.out.println(i);  // ✅ 可以访问
    }
}
```
## 五、一句话记忆

> **类体里方法外 = 只能贴“标签”（变量/方法），不能写“动作”（语句）**  
> **`static int i` 是标签，所有方法都能看到它**

# 成员变量没有手动赋值,系统会默认赋值(局部变量不会)，**默认值一切向0看齐**
## 一、核心规则

> **成员变量**：不手动赋值 → 系统给默认值（向0看齐）  
> **局部变量**：不手动赋值 → 编译报错（必须手动赋值）
## 二、默认值对照表（向0看齐）

| 数据类型 | 默认值 | 解释 |
|---------|--------|------|
| `byte` | 0 | 整数0 |
| `short` | 0 | 整数0 |
| `int` | 0 | 整数0 |
| `long` | 0L | 整数0 |
| `float` | 0.0f | 小数0 |
| `double` | 0.0 | 小数0 |
| `char` | `'\u0000'` | 空字符（也是0） |
| `boolean` | false | 布尔0（假=0） |
| 引用类型（String等） | null | 空指针（指向0地址） |

> **“向0看齐”**：数值→0，布尔→false，引用→null
## 三、成员变量示例（有默认值）

```java
public class Person {
    int age;        // ✅ 默认 0
    String name;    // ✅ 默认 null
    boolean isMale; // ✅ 默认 false

    public void show() {
        System.out.println(age);     // 输出 0
        System.out.println(name);    // 输出 null
        System.out.println(isMale);  // 输出 false
    }

    public static void main(String[] args) {
        new Person().show();
    }
}
```

**输出：**
```
0
null
false
```

## 四、局部变量示例（没有默认值）

```java
public class Test {
    public void method() {
        int i;           // 只声明，没赋值
        // System.out.println(i);  // ❌ 编译报错：变量i未初始化

        i = 10;          // 手动赋值后
        System.out.println(i);  // ✅ 输出 10
    }
}
```

## 五、为什么会有这个区别？

| | 成员变量 | 局部变量 |
|--|---------|---------|
| **存储位置** | 堆内存（对象）或方法区（静态） | 栈内存 |
| **生命周期** | 对象/类存在就一直存在 | 方法调用完就消失 |
| **默认值来源** | JVM在分配内存时会**自动清零** | 栈帧分配时**不清零**（懒） |
| **设计理由** | 安全性，避免读到垃圾值 | 性能，没必要清零（而且你必须主动赋值）|

## 六、最容易翻车的例子

```java
public class Demo {
    int a;        // 默认0 ✅

    public void test() {
        int b;     // 没有默认值 ❌
        System.out.println(b);  // 编译报错！
    }
}
```

**错误信息：**
```
变量b可能尚未初始化
```
