## uv 启动





核心依赖：

Web框架：FastAPI（高性能异步框架）
ORM：SQLAlchemy（Python最主流ORM）
异步驱动：asyncmy实现MySQL异步访问，（配合SQLAlchemy实现全异步数据库访问）
向量数据库：Qdrant（轻量级易维护）
全文检索：Elasticsearch（异步客户端）
LLM框架：LangChain（应用编排框架）

扩展依赖：

自然语言处理：jieba分词、langchain框架
配置文件处理：omegaconf、pyyaml
日志管理：loguru（替代logging）
全文检索：elasticsearch[async]8.x版本
加密支持：cryptography
