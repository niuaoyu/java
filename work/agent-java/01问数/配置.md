



# SQLAlchemy + AysncSession + 连接池

FastAPI -- services -- repository -- SQLAlchemy -- conn pool --asyncmy --mysql

SQLAlchemy负责数据库连接，连接池，session，orm，sql构造，事务管理
asyncmy 负责 和 mysql通信

```
app/
└── db/
    ├── mysql.py   # 数据库相关的东西
    ├── session.py # 负责 数据库引擎engine --> conn pool --> AsyncSession 
    └── __init__.py 让 `db` 成为 Python package
```

```mermaid
flowchart TD
    A[FastAPI 接收请求] --> B[services 业务逻辑]
    B --> C[repository 数据访问]
    C --> D{SQLAlchemy 核心}
    
    subgraph D [SQLAlchemy 管家]
        D1[create_async_engine<br>（建立后厨总水阀）]
        D2[async_sessionmaker<br>（培训服务员）]
        D3[AsyncSession<br>（单个服务员）]
    end
    
    D1 --> E[asyncmy 连接池<br>（水龙头缓存池）]
    E --> F[(MySQL 数据库)]
    
    D2 --> D3
    D3 --> E
```
