	高性能：原生支持异步(async/await)，性能优于Flask和Django框架
	自动校验：使用Pydantic自动类型校验，提供类型提示与验证功能，减少手动校验代码
	文档生成：自动生成交互式API文档，方便前后端调试测试
	开发效率：减少手动校验，提升开发速度
适用场景：API开发、微服务、AI推理部署
