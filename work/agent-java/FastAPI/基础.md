
核心优势：
	高性能：原生支持异步(async/await)，性能优于Flask和Django框架
	自动校验：使用Pydantic自动类型校验，提供类型提示与验证功能，减少手动校验代码
	文档生成：自动生成交互式API文档，方便前后端调试测试
	开发效率：减少手动校验，提升开发速度
适用场景：API开发、微服务、AI推理部署


**路由**就是请求url路径和对应处理函数之间的映射关系，也就是 @app.get("/") 就是路由，建立二者之间的联系
**模块化路由**就是把每个业务功能的接口拆分到独立文件里，再统一挂载到主应用中。


中间件：函数的顶部使用装饰器 @app.middleware("http")
中间件作用是为每个请求添加统一的处理逻辑（记录日志、身份认证、跨域、设置响应头、性能监控等）

使用依赖注入系统来共享通用逻辑，避免代码重复，一次编写多处使用，业务和基础设施分离
怎么使用依赖注入系统？创建依赖项→导入Depends →声明依赖项
```python
from fastapi import Depends
async def common_parameters(
	skip:int=Query(0,ge=0),
	limit:int=Query(10,le=60)
):
	return{"skip":skip,"limit":limit}
	
@app.get("news/news_list'")
async def get_news_list(
	commons=Depends(common_parameters)
):
	return commons
```

ORM（Object-RelationalMapping，对象关系映射）是一种编程技术，用于在面向对象编程语言和关系型数据库之间建立映射。它允许开发者通过操作对象的方式与数据库进行交互，而无需直接编写复杂的SQL语句。

SQLAlchemy ORM功能最强、最灵活、企业级，适用于各类API、微服务、数据应用
Django ORM封装好、上手快，适用于Django项目、管理后台
Tortoise ORM全异步，适用于异步Web服务、高并发API
