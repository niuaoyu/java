Pydantic提供类型提示与验证功能，减少手动校验代码，如何理解？

### 1. 自动类型转换和验证

```python
from pydantic import BaseModel

class User(BaseModel):
    username: str
    password: str
    age: int  # 注意这里是 int

# ✅ 正确使用
user1 = User(username="alice", password="123", age=25)
print(user1)  # username='alice' password='123' age=25

# ❌ Pydantic 自动验证并报错
user2 = User(username="alice", password="123", age="二十五")
# 报错：age: value is not a valid integer

# ⚠️ 自动类型转换（如果能转的话）
user3 = User(username="alice", password="123", age="25")  # 字符串 "25"
print(user3.age)  # 25 (自动转成了 int)
print(type(user3.age))  # <class 'int'>
```

### 2. 在 FastAPI 中的实际工作流程

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class User(BaseModel):
    username: str
    password: str
    age: int

@app.post("/register")
async def register(user: User):
    # FastAPI + Pydantic 在调用这个函数之前做了这些事：
    # 1. 接收 HTTP 请求的 JSON body
    # 2. 自动解析 JSON
    # 3. 用 Pydantic 验证数据
    # 4. 如果验证通过，才调用这个函数
    # 5. 如果验证失败，自动返回 422 错误
    return {"username": user.username, "age": user.age}
```
### ❌ 没有 Pydantic（手动验证）

```python
from fastapi import FastAPI, Request, HTTPException
import json

app = FastAPI()

@app.post("/register_manual")
async def register_manual(request: Request):
    # 1. 手动解析 JSON
    body = await request.body()
    try:
        data = json.loads(body)
    except:
        raise HTTPException(400, "Invalid JSON")
    
    # 2. 手动检查字段是否存在
    if "username" not in data:
        raise HTTPException(400, "username required")
    if "password" not in data:
        raise HTTPException(400, "password required")
    if "age" not in data:
        raise HTTPException(400, "age required")
    
    # 3. 手动检查类型
    if not isinstance(data["username"], str):
        raise HTTPException(400, "username must be string")
    if not isinstance(data["password"], str):
        raise HTTPException(400, "password must be string")
    if not isinstance(data["age"], int):
        raise HTTPException(400, "age must be integer")
    
    # 4. 手动检查业务规则
    if len(data["username"]) < 3:
        raise HTTPException(400, "username too short")
    if len(data["password"]) < 6:
        raise HTTPException(400, "password too short")
    
    # 5. 终于可以使用数据了
    return {"username": data["username"], "age": data["age"]}
```

**这段代码有 30+ 行！全是手动验证！**

### ✅ 有 Pydantic（自动验证）

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class User(BaseModel):
    username: str = Field(..., min_length=3, description="用户名")
    password: str = Field(..., min_length=6, description="密码")
    age: int = Field(..., ge=0, le=150, description="年龄")

@app.post("/register")
async def register(user: User):
    # 所有验证已经自动完成了！
    # 只需要使用数据即可
    return {"username": user.username, "age": user.age}
```

**只有 10 行代码，验证全自动！**

## Pydantic 提供的更多验证功能

```python
from pydantic import BaseModel, Field, EmailStr, validator
from datetime import datetime
from typing import Optional, List

class User(BaseModel):
    # 1. 基本类型验证
    username: str = Field(..., min_length=3, max_length=20)
    email: EmailStr  # 自动验证邮箱格式
    age: int = Field(ge=0, le=150)
    
    # 2. 可选字段
    nickname: Optional[str] = None
    
    # 3. 复杂类型
    tags: List[str] = []
    created_at: datetime = datetime.now()
    
    # 4. 自定义验证
    @validator('username')
    def username_alphanumeric(cls, v):
        if not v.isalnum():
            raise ValueError('username must be alphanumeric')
        return v
    
    @validator('age')
    def age_valid(cls, v):
        if v < 0 or v > 150:
            raise ValueError('age must be between 0 and 150')
        return v

# 测试
try:
    user = User(
        username="alice!@#",  # ❌ 包含特殊字符
        email="invalid-email",  # ❌ 邮箱格式错误
        age=200  # ❌ 年龄超出范围
    )
except Exception as e:
    print(e)
    # 会报错：username must be alphanumeric
    # 会报错：value is not a valid email address
    # 会报错：age must be between 0 and 150
```

## 总结

**"减少手动校验代码"体现在：**

| 手动校验（30+行） | Pydantic（几行） |
|------------------|------------------|
| 手动解析 JSON | 自动解析 |
| 检查字段是否存在 | 自动检查 |
| 检查类型是否正确 | 自动类型验证 |
| 检查长度/范围 | Field 自动验证 |
| 自定义业务规则 | validator 装饰器 |
| 返回错误信息 | 自动返回 422 错误 |

**核心价值：**
- 📝 **声明式**：只需要声明"要什么"，不需要写"怎么验证"
- 🛡️ **类型安全**：编译时和运行时都有类型检查
- 🚀 **开发效率**：节省 80% 的验证代码
- 📚 **自动文档**：验证规则自动生成 API 文档

这就是为什么 FastAPI + Pydantic 这么受欢迎！你写的是业务逻辑，Pydantic 帮你处理验证！✨
