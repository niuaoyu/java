
## 一、三种参数的核心区别

用**快递寄送**来类比：

```
┌─────────────────────────────────────────────────────────┐
│  寄快递类比                                            │
│                                                         │
│  📦 路径参数 = 收件人ID                                │
│     作用：确定是哪个快递单                             │
│     例如：/express/{tracking_number}                   │
│                                                         │
│  🔍 查询参数 = 快递筛选条件                            │
│     作用：过滤、排序、分页                             │
│     例如：?status=已签收&page=1&size=10                │
│                                                         │
│  📝 请求体参数 = 包裹内容                              │
│     作用：提交数据、创建、更新                         │
│     例如：{"sender":"张三","receiver":"李四",...}      │
└─────────────────────────────────────────────────────────┘
```

## 二、路径参数（Path Parameters）

### 特征
- **位置**：URL 路径的一部分
- **作用**：指向**唯一的、特定的**资源
- **常用方法**：GET、DELETE、PUT
- **示例**：`/user/123`、`/product/iphone-15`

### 代码示例

```python
from fastapi import FastAPI

app = FastAPI()

# 路径参数：{user_id}
@app.get("/user/{user_id}")
async def get_user(user_id: int):
    """
    获取特定用户的信息
    URL: /user/123
    user_id = 123
    """
    return {"user_id": user_id, "name": f"User_{user_id}"}

# 多个路径参数
@app.get("/user/{user_id}/order/{order_id}")
async def get_user_order(user_id: int, order_id: int):
    """
    URL: /user/123/order/456
    user_id = 123, order_id = 456
    """
    return {
        "user_id": user_id,
        "order_id": order_id,
        "order": f"订单{order_id}属于用户{user_id}"
    }

# 路径参数 + 类型验证
@app.get("/product/{product_id}")
async def get_product(product_id: int):  # FastAPI 自动验证是否为 int
    return {"product_id": product_id, "name": f"Product_{product_id}"}
```

### 前端请求示例

```javascript
// 获取用户 123 的信息
fetch('http://localhost:8000/user/123')

// 获取用户 123 的订单 456
fetch('http://localhost:8000/user/123/order/456')
```

## 三、查询参数（Query Parameters）

### 特征
- **位置**：URL 的 `?` 之后
- **格式**：`key1=value1&key2=value2`
- **作用**：过滤、排序、分页
- **常用方法**：GET
- **特点**：可有可无，有默认值

### 代码示例

```python
from fastapi import FastAPI
from typing import Optional

app = FastAPI()

# 基本查询参数
@app.get("/news/list")
async def get_news_list(
    skip: int = 0,          # 跳过的数量，默认 0
    limit: int = 10,        # 返回的数量，默认 10
    category: str = "all"   # 分类，默认 all
):
    """
    URL: /news/list?skip=20&limit=5&category=tech
    
    注意：路径参数和查询参数如何区分？
    - 路径参数：在 URL 路径中（/user/{id}）
    - 查询参数：在 ? 后面（?skip=20）
    - FastAPI 自动识别：没有在路径中的参数就是查询参数
    """
    return {
        "skip": skip,
        "limit": limit,
        "category": category,
        "data": [f"新闻{i}" for i in range(skip, skip + limit)]
    }

# 可选查询参数
@app.get("/products")
async def get_products(
    name: Optional[str] = None,   # 可选参数
    min_price: float = 0,
    max_price: float = 10000,
    sort_by: str = "price"
):
    """
    URL: /products?name=iphone&min_price=5000&max_price=8000
    """
    return {
        "filters": {
            "name": name,
            "min_price": min_price,
            "max_price": max_price,
            "sort_by": sort_by
        }
    }

# 布尔类型查询参数
@app.get("/users")
async def get_users(
    active_only: bool = True,  # URL: /users?active_only=false
    page: int = 1
):
    return {
        "active_only": active_only,
        "page": page,
        "users": ["Alice", "Bob"]
    }
```

### 前端请求示例

```javascript
// 获取新闻列表，跳过 20 条，取 5 条，科技类
fetch('http://localhost:8000/news/list?skip=20&limit=5&category=tech')

// 搜索产品
fetch('http://localhost:8000/products?name=iphone&min_price=5000&max_price=8000')

// 获取活跃用户，第二页
fetch('http://localhost:8000/users?active_only=true&page=2')
```

## 四、请求体参数（Request Body）⭐

### 特征
- **位置**：HTTP 请求的**消息体**中
- **作用**：创建、更新资源，提交大量数据
- **格式**：JSON（最常用）、XML、表单等
- **常用方法**：POST、PUT、PATCH
- **特点**：数据量大，结构复杂

### 为什么需要请求体？

```python
# ❌ 路径参数/查询参数：不适合复杂数据
# 如果要注册用户，有 10 个字段怎么办？
GET /register?username=alice&password=123&email=alice@test.com&age=25&address=...
# URL 太长！不安全（密码暴露在 URL 中）！数据量有限制！

# ✅ 请求体：完美解决
POST /register
Body: {
    "username": "alice",
    "password": "123456",
    "email": "alice@test.com",
    "age": 25,
    "address": "北京",
    "phone": "13800138000",
    "hobbies": ["reading", "swimming"]
}
# 数据安全、数据量大、结构清晰！
```

### 完整示例：请求体参数

```python
from fastapi import FastAPI
from pydantic import BaseModel
from typing import Optional, List
from datetime import datetime

app = FastAPI()

# ========== 1. 定义请求体模型 ==========
class UserRegister(BaseModel):
    """用户注册请求体"""
    username: str
    password: str
    email: str
    age: Optional[int] = None
    phone: Optional[str] = None

class UserProfile(BaseModel):
    """用户资料更新请求体"""
    name: str
    bio: str
    avatar_url: str
    tags: List[str] = []

class OrderCreate(BaseModel):
    """创建订单请求体"""
    user_id: int
    product_ids: List[int]
    quantities: List[int]
    address: str
    remark: Optional[str] = None

# ========== 2. 使用请求体 ==========
@app.post("/register")
async def register_user(user: UserRegister):
    """
    用户注册
    请求体：JSON 格式的用户信息
    """
    return {
        "code": 200,
        "message": f"用户 {user.username} 注册成功",
        "data": {
            "username": user.username,
            "email": user.email,
            "age": user.age,
            "phone": user.phone
        }
    }

@app.put("/user/profile")
async def update_profile(profile: UserProfile):
    """
    更新用户资料
    请求体：JSON 格式的资料信息
    """
    return {
        "code": 200,
        "message": "资料更新成功",
        "data": profile
    }

@app.post("/order/create")
async def create_order(order: OrderCreate):
    """
    创建订单
    请求体：JSON 格式的订单信息
    """
    total_price = len(order.product_ids) * 100  # 简化计算
    return {
        "code": 200,
        "message": "订单创建成功",
        "order_id": 12345,
        "total_price": total_price,
        "products": order.product_ids
    }

# ========== 3. 混合使用三种参数 ==========
@app.post("/user/{user_id}/orders")
async def create_user_order(
    user_id: int,                      # 路径参数
    order_type: str = "normal",        # 查询参数
    order_data: OrderCreate            # 请求体
):
    """
    为用户创建订单
    - 路径参数：{user_id} 指定用户
    - 查询参数：?order_type=normal 指定类型
    - 请求体：订单详细数据
    """
    return {
        "user_id": user_id,
        "order_type": order_type,
        "order_data": order_data
    }
```

## 五、三种参数的对比总结

| 特性 | 路径参数 | 查询参数 | 请求体参数 |
|------|---------|---------|-----------|
| **位置** | URL 路径中 | URL `?` 后面 | HTTP 消息体 |
| **示例** | `/user/123` | `?page=1&size=10` | `{"username":"alice"}` |
| **可见性** | 可见 | 可见 | 不可见（body 中） |
| **数据大小** | 小 | 小 | 大（可以很多） |
| **安全性** | 中（URL 可见） | 低（URL 可见） | 高（不在 URL 中） |
| **用途** | 标识特定资源 | 过滤、排序、分页 | 创建、更新资源 |
| **常用方法** | GET, DELETE, PUT | GET | POST, PUT, PATCH |
| **是否必需** | 通常必需 | 可选 | 通常必需 |
| **数据类型** | 简单类型 | 简单类型 | 复杂结构（JSON） |

## 六、实战场景

### 场景 1：获取用户信息

```python
# 路径参数：指定用户
@app.get("/user/{user_id}")
async def get_user(user_id: int):
    return {"user_id": user_id}

# 查询参数：筛选条件
@app.get("/users")
async def get_users(
    age_min: int = 0,
    age_max: int = 100,
    active: bool = True
):
    return {"filters": {"age_min": age_min, "age_max": age_max, "active": active}}
```

### 场景 2：创建资源

```python
# 请求体：提交数据
@app.post("/user")
async def create_user(user: UserRegister):
    return {"message": "User created"}

# 混合使用：路径参数 + 请求体
@app.post("/user/{user_id}/orders")
async def create_order(
    user_id: int,              # 路径参数：为谁创建
    order: OrderCreate         # 请求体：订单数据
):
    return {"user_id": user_id, "order": order}
```

### 场景 3：更新资源

```python
# 路径参数 + 请求体
@app.put("/user/{user_id}")
async def update_user(
    user_id: int,              # 路径参数：更新谁
    user_data: UserProfile     # 请求体：更新内容
):
    return {"user_id": user_id, "updated_data": user_data}

# 查询参数 + 请求体
@app.patch("/user/{user_id}")
async def partial_update(
    user_id: int,
    fields: str = "all",       # 查询参数：更新哪些字段
    user_data: UserProfile     # 请求体：更新内容
):
    return {"fields": fields, "data": user_data}
```

## 七、curl 命令对比

```bash
# 1. 路径参数（在 URL 中）
curl http://localhost:8000/user/123

# 2. 查询参数（在 ? 后面）
curl "http://localhost:8000/users?age_min=18&active=true"

# 3. 请求体参数（在 -d 中）
curl -X POST http://localhost:8000/register \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"123456"}'

# 4. 混合使用
curl -X POST "http://localhost:8000/user/123/orders?type=express" \
  -H "Content-Type: application/json" \
  -d '{"product_ids":[1,2],"quantities":[1,1]}'
```

## 八、核心要点记忆口诀

```
路径参数路径中，标识资源唯一性
查询参数问号后，过滤排序和分页
请求体在消息体，创建更新用 POST
三种参数可混用，各司其职要分清
```

**重点记住：**
- 📍 **路径参数**：`/user/123` → 定位特定资源
- 🔍 **查询参数**：`?page=1&size=10` → 筛选和排序
- 📦 **请求体**：`{"name":"Alice"}` → 提交大量数据，最常用在 POST/PUT

请求体参数是最强大的，因为它可以传输复杂的数据结构，是 RESTful API 中创建和更新资源的标准方式！🎯
