
Hooks（钩子）：在生命周期事件上自动执行脚本，这些**必定发生的事由物理规则**保证。

**在特定生命周期事件**（比如工具调用前/后、会话开始）自动跑用户配置的 shell 命令，跟模型的决策完全无关，是宿主程序层面的自动化，模型甚至不知道 hook 触发了

没有 Hooks 的 AI 协作 = 雇了一个聪明但健忘的实习生，你每次都要口头提醒“出门前锁门、关灯、带工牌”。
有 Hooks 的 AI 协作 = 给门装了自动锁、灯装了定时器、工牌绑定了 GPS。实习生只管干活，这些“必定发生”的事由物理规则保证。


一次配置，永久生效，prompt 可以更简洁
