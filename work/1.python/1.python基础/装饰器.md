
```python
# engine/runner.py
print("1. 开始执行 runner.py 模块代码")

RUNNER_REGISTRY = {}
print(f"2. RUNNER_REGISTRY 初始为: {RUNNER_REGISTRY}")

def register_runner(name):
    print(f"3. register_runner 被调用，name={name}")
    def decorator(cls):
        print(f"4. decorator 被调用，cls={cls.__name__}")
        RUNNER_REGISTRY[name] = cls
        print(f"5. 注册完成，RUNNER_REGISTRY = {RUNNER_REGISTRY}")
        return cls
    return decorator

class Runner:
    pass

print("6. 准备定义 StandardRunner...")

@register_runner("standard")
class StandardRunner(Runner):
    def run(self):
        return "StandardRunner 执行"

print("7. StandardRunner 定义完成")
print(f"8. 最终 RUNNER_REGISTRY = {RUNNER_REGISTRY}")
```

**装饰器就是一个函数调用，在类定义完成后立即执行！**

为什么导入模块遇到 `@register_runner` 就自动填充了？**答案：** 因为 `@` 装饰器语法**不是标记**，而是**函数调用**。

**`@register_runner("standard")` 不是"标记这个类要被注册"，而是"定义这个类后，立即调用 register_runner 函数，把类存入字典"**

```python
@register_runner("standard")
class StandardRunner:
    pass
==============等价于
class StandardRunner:
    pass
StandardRunner = register_runner("standard")(StandardRunner)
```

```text
# 第1步：调用 register_runner("standard")
# 输出: "register_runner 被调用，name=standard"
# 返回 decorator 函数 也就是说register_runner("standard") == decorator
register_runner("standard")(StandardRunner) == decorator(StandardRunner)

# 第2步：调用 decorator(StandardRunner)
# 输出: "decorator 被调用，cls=StandardRunner"
# 执行: RUNNER_REGISTRY["standard"] = StandardRunner
# 返回: StandardRunner
# 最终：RUNNER_REGISTRY = {"standard": StandardRunner}
```


```python
# ========== 第1步：创建 engine/runner.py ==========
# engine/runner.py 内容如下：

print(">>> 加载 runner.py")

RUNNER_REGISTRY = {}

def register_runner(name):
    def decorator(cls):
        print(f">>> 注册 {name} -> {cls.__name__}")
        RUNNER_REGISTRY[name] = cls
        return cls
    return decorator

class Runner:
    pass

@register_runner("standard")
class StandardRunner(Runner):
    def run(self):
        return "StandardRunner 执行"

print(f">>> 加载完成，RUNNER_REGISTRY = {RUNNER_REGISTRY}")


# ========== 第2步：主程序中导入 ==========
# main.py

print("=" * 40)
print("主程序开始")
print("=" * 40)

print("即将导入 engine.runner...")
import engine.runner  # ← 这一行触发了上面的所有打印
print("导入完成")

print(f"RUNNER_REGISTRY = {engine.runner.RUNNER_REGISTRY}")
```

```text
========================================
主程序开始
========================================
即将导入 engine.runner...
>>> 加载 runner.py
>>> 注册 standard -> StandardRunner
>>> 加载完成，RUNNER_REGISTRY = {'standard': <class 'StandardRunner'>}
导入完成
RUNNER_REGISTRY = {'standard': <class 'StandardRunner'>}
```

导入 `engine` 包时，Python 会逐层导入，每一层的 `from .xxx import yyy` 都会触发 `xxx.py` 的执行，从而执行 `@register_reconstructor` 装饰器。从而注册对象！！！
