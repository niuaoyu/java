

uv的项目添加路径

首先在所有的包里添加__init__.py，接着在pyproject.toml 里添加这些内容，然后重新uv sync即可

```toml
[project]
name = "rag"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
    # 你已有的依赖...
    "loguru",
    "python-dotenv",
]
# 上面是原本存在的，下面是新加的
[tool.uv]
package = true

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[tool.hatch.build.targets.wheel]
packages = ["app"]
```
